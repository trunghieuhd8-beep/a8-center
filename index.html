A8 Center

Cài A8 Center một lần, sau đó cài và cập nhật các plugin A8 ngay trong SketchUp.

Tải A8 Center 1.1.1 (.rbz)

Cách cài: SketchUp → Extensions → Extension Manager → Install Extension → chọn file vừa tải → khởi động lại SketchUp một lần. Sau đó mở Extensions → A8 Center.

Plugin hiện có

  • A8 Center 1.1.1 Trung tâm cài đặt và cập nhật các plugin A8.
  • A8 Model Tools 0.3.5 Dán CAD, gộp/khấu khối, dọn nét, tường CAD, sàn, tủ, CNC, chỉ âm tường, chữ 3D…
  • ARCH - HIEU HSNT 2D 4.10.2 Triển khai hồ sơ nội thất 2D từ model: chi tiết đồ, hồ sơ phòng, điện nước, xuất PDF / DXF. Dùng miễn phí có đóng dấu; xuất file cần key.
  • HIEU ARCH 2D 6.0.1 Khai báo tầng, trục, cấu kiện, phòng, mã → tự tạo bộ hồ sơ kiến trúc 2D. Xuất PDF và DXF.
  • A8 Max Fix 1.1.0 Xử lý model import từ 3ds Max: gộp tam giác đồng phẳng, hiện lại nét cạnh, xóa vát cạnh nhỏ, file nhẹ hơn.
