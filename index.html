A8 Center

Cài A8 Center một lần, sau đó cài và cập nhật các plugin A8 ngay trong SketchUp.

Tải A8 Center 1.0.1 (.rbz)

Cách cài: SketchUp → Extensions → Extension Manager → Install Extension → chọn file vừa tải → khởi động lại SketchUp một lần. Sau đó mở Extensions → A8 Center.

  • A8 Center 1.0.1 Trung tâm cài đặt và cập nhật các plugin A8.
